Hybrid Inheritance
Hybrid inheritance is a type that combines two or more inheritance
types within a single class hierarchy.
1.   Combines multiple inheritance types such as single, multiple,
     multilevel and hierarchical inheritance
2.   Provides greater flexibility in designing class hierarchies.
3.   Can lead to ambiguity issues such as the diamond problem.
                                                                     27
           Diamond Problem in Hybrid Inheritance
The Diamond Problem occurs in C++ during multiple inheritance
when a derived class inherits from two base classes that themselves
inherit from a common base class. This creates ambiguity because the
derived class ends up with multiple copies of the same base class
members, making member access unclear.
Solution to Diamond Problem
The Diamond Problem can be solved using Virtual inheritance.
Virtual inheritance ensures that only one shared instance of the base
class exists, regardless of how many times it is inherited.

2. Using nullptr (Modern C++)

                   Types of Pointer
1. Null pointer
A null pointer doesn’t point to any memory location. Null pointer helps to
ensure that a pointer does not accidentally reference garbage memory.
2. Void pointer
A void pointer (also called a generic pointer) can hold the memory address of
any data type, but it cannot be dereferenced directly without typecasting.
                                                                                47
3. Dangling pointer
A dangling pointer is one that points to memory that has already been
freed or deleted.
4. Wild pointer
A wild pointer is an uninitialized pointer that points to a random
memory location.
                                                                        48
5. Constant pointer
constant pointer is a pointer that, once initialized, cannot point to a
different address, but the value stored at that address can still be
modified
